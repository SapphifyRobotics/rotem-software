# Contributing

Open an issue before large interface changes. Keep firmware, Java and TypeScript units and axes consistent with `protocol/wire-0.6.md`. Include a failing test or reproducible bench procedure for fixes. State whether evidence is a simulation, software test or physical measurement.

Run the checks in README before a pull request. Never commit credentials, USB serial numbers, private recordings, production CAD or factory files. Do not attach raw logs until reviewing them. Small, focused pull requests and documentation corrections are welcome.

Changes to wire format require a compatibility decision, fixtures and a changelog entry. Hardware qualification is recorded separately from compilation. A maintainer reviews releases; experimental releases must retain their limitations.
